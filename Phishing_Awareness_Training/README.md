# Phishing Awareness Training

## Overview

This project provides a comprehensive awareness training on phishing attacks, social engineering techniques, and cybersecurity best practices. The training is designed to educate users on how phishing attacks work, how attackers manipulate human behavior, and how individuals can protect themselves from becoming victims.

The presentation includes real-world phishing attack simulations conducted in a controlled laboratory environment for educational purposes only.

## Project Information

**Title:** Phishing Awareness Training

## Objectives

The primary objectives of this training are to:

* Understand what phishing attacks are
* Learn how phishing campaigns operate
* Identify common phishing indicators
* Recognize social engineering tactics used by attackers
* Detect fake websites and malicious emails
* Apply cybersecurity best practices to reduce risk
* Improve overall security awareness

---

## Topics Covered

### 1. Introduction to Phishing

* Definition of phishing
* Why phishing is effective
* Types of phishing attacks

### 2. Common Types of Phishing

* Email Phishing
* Smishing (SMS Phishing)
* Vishing (Voice Phishing)
* Business Email Compromise (BEC)

### 3. How Phishing Works

A simplified attack flow showing how attackers:

1. Create a fake website or email
2. Deliver malicious content
3. Trick victims into clicking links
4. Capture credentials or sensitive information

### 4. Phishing Simulation Demonstration

A controlled laboratory demonstration using:

* Linux Environment
* MedusaPhisher / Zphisher
* Facebook Login Page Clone
* Isolated Test Network

**Note:** This simulation was conducted strictly for educational and cybersecurity awareness purposes within a controlled environment.

### 5. Social Engineering Techniques

Common psychological manipulation methods used by attackers:

* Urgency
* Fear
* Authority
* Curiosity
* Rewards

### 6. Identifying Phishing Emails

How to recognize:

* Suspicious sender addresses
* Mismatched domains
* Poor grammar and spelling
* Unexpected attachments
* Urgent requests

### 7. Detecting Fake Websites

Indicators of malicious websites:

* HTTP instead of HTTPS
* Misspelled domains
* Invalid certificates
* Poor website design
* Fake login portals

### 8. Security Best Practices

Recommended defensive measures:

* Verify before acting
* Avoid clicking unknown links
* Use Multi-Factor Authentication (MFA)
* Create strong passwords
* Keep software updated
* Enable browser anti-phishing protection

### 9. Interactive Quiz

A cybersecurity awareness assessment covering:

* Email security
* Social engineering
* Website verification
* Password safety
* MFA implementation

### 10. Conclusion

Summary of phishing risks and practical recommendations for maintaining personal and organizational cybersecurity.
